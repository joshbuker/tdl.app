# Triage review

Status: Proposed
Related: [Schedule](schedule.md)

## Summary

The user steps through a set of tasks one at a time and decides what to do with each: do it now, postpone it, complete it, or delete it.

## Design intent

Two earlier versions: #1's Review dialog stepped through Today with Now, Later (Tomorrow, Next week, Upcoming, Someday), Done and Delete. #3's GTD period had a "very hefty" clarify flow (Actionable? More than one action? Under two minutes? Delegate? Defer?). Both were partly finished. The goal is to process a backlog quickly with one decision per task.
