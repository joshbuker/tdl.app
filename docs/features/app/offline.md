# Offline use

Status: Proposed
Related: [Platforms](platforms.md)

## Summary

The user can view and change tasks without a connection, and changes sync when back online.

## Design intent

#3 cached data locally so it could be read offline, but every change went straight to the server. A TODO noted client-generated IDs as the first step towards offline creation. A mobile todo app is often used with poor signal.
