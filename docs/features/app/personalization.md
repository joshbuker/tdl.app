# Personalization

Status: Proposed

## Summary

Display preferences: which pages appear in navigation, the default page, background, notification duration, and sounds.

## Design intent

From #3, where each of these was a setting. #3 also played a sound when checking or unchecking a task.

## Rules

- The default page is chosen from the enabled pages.
- Navigation can be reset to the default set of pages.
