# Energy levels

Status: Proposed
Related: [Filtering and sorting](../views/filtering-and-sorting.md)

## Summary

Each task records how much mental and physical energy it needs, from 0 to 100.

## Design intent

Introduced in #3's GTD period and kept after it, presumably to pick tasks matching current energy. No feature ever used the values.

## Rules

- Each value is 0 to 100. The default is 50.

## Scenarios

- To be defined.

## Open questions

- What would use these values (filtering, sorting, an auto-scheduler)? Without a use, should they exist at all?
